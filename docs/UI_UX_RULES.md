# UI/UX Rules

## General

- Build production-quality interfaces.
- Avoid generic AI-generated UI.
- Prefer visual hierarchy over decoration.
- Use consistent spacing.
- Use a limited color palette.
- Avoid unnecessary gradients.
- Avoid excessive rounded cards.
- Avoid excessive shadows.
- Avoid visual noise.

## Layout

- Use a consistent spacing scale.
- Maintain strong alignment.
- Establish clear content hierarchy.
- Use responsive layouts.
- Avoid arbitrary pixel positioning.

## Typography

- Use a deliberate type scale.
- Headings must have clear hierarchy.
- Body text must remain readable.
- Avoid excessive font weights.

## Components

- Reuse components.
- Do not create visually different versions of the same component unnecessarily.
- Buttons must have consistent sizing.
- Inputs must have consistent height, radius and states.
- Cards should be used only when they improve hierarchy.

## UX

Every screen should consider:

- loading state
- empty state
- error state
- success state
- disabled state
- hover state
- focus state
- mobile behavior
- accessibility

## Responsive

Design for:

- mobile
- tablet
- desktop

Do not simply shrink the desktop layout.

## Visual Quality

Before considering a screen complete:

1. Check spacing.
2. Check typography hierarchy.
3. Check alignment.
4. Check responsive behavior.
5. Check visual density.
6. Check consistency with DESIGN.md.
7. Check empty/loading/error states.
