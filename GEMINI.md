# GEMINI.md

Athenaeum Library Management System with two independent applications:

- `backend/` — Spring Boot 4.0.6, Java 21, Maven
- `frontend/` — Vue 3, Vite, Nuxt UI v4, Tailwind 4, Apache ECharts, AG Grid, pnpm

## Working Style & General Rules

- **Targeted Inspection:** Inspect only the files relevant to the task before changing anything.
- **Direct Implementation:** Implement directly when the request is clear — avoid unnecessary planning phases or asking obvious clarifying questions.
- **Localized Changes:** Keep changes small, clean, and localized; reuse existing code, composables, services, components, and design tokens.
- **Do Not Modify Unrelated Files:** Avoid refactoring working components or altering unrelated architecture.
- **Dev Servers:** Never start, stop, or restart the backend (`spring-boot:run`) or frontend (`pnpm dev`) dev server processes. Assume both are running and managed by the user.
- **Tooling & Search:** Prefer `grep_search` and `find_by_name` to locate specific endpoints, methods, or components before reading full files.

---

## Backend Guidelines

Run commands from `backend/`:

```bash
.\mvnw spring-boot:run
.\mvnw test
.\mvnw compile
```

- **Port:** `5050`.
- **Database:** SQL Server on `localhost:1433`, database `library`.
- **Schema Management:** Hibernate `ddl-auto=update` (no separate migration scripts).
- **Authentication:** All routes except `/api/auth/**` and `/error` require JWT authentication.
- **Controllers & Services:** Inject service interfaces into controllers following the existing pattern.
- **Category Service:** Maintain `CategoryServiceImp` as the implementation name.
- **Responses & Errors:** Return standard `payload.ApiResponse` envelopes; handle exceptions via `GlobalExceptionHandler`.
- **Lombok:** Used across entities, DTOs, and controllers.

## Frontend Guidelines

Run commands from `frontend/`:

```powershell
$env:CI="true"; pnpm typecheck
$env:CI="true"; pnpm build
$env:CI="true"; pnpm lint
```

- **Package Manager:** Always use `pnpm`; never `npm` or `yarn`.
- **Routing:** File-based routes generated by `vue-router/auto` from `src/pages/`.
- **Nuxt UI v4:** Nuxt UI components are auto-imported (e.g. `UButton`, `UInput`, `UIcon`, `UModal`, `UBadge`, `UDropdownMenu`, `UBreadcrumb`). Do not import them manually.
- **Class Overrides:** Nuxt UI's `ui` prop appends to theme classes; use Tailwind's `!` prefix for explicit overrides (e.g. `class="!rounded-lg !px-8"`).
- **Code Style:** Vue 3 Composition API with `<script setup lang="ts">` and 2-space indentation.

## UI & Design System (Athenaeum)

The Athenaeum design system combines modern SaaS cleanliness with refined editorial typography:

- **Primary Color:** Deep Navy Blue (`#1E3A5F` / `brand-600`)
- **Primary Light:** Steel Blue (`#4A7A9D` / `brand-400`)
- **Secondary Accent:** Warm Amber (`#D4A017` / `amber-500`)
- **Semantic Colors:**
  - Success: Forest Green (`#2E7D32`)
  - Warning: Amber Orange (`#F59E0B`)
  - Danger / Overdue: Muted Red (`#C0392B`)
  - Info: Soft Teal (`#3B9C9C`)
- **Neutrals:**
  - Background: Off-White (`#F7F8FA`)
  - Cards & Surfaces: White (`#FFFFFF`)
  - Borders: Light Gray (`#E1E4E8`)
  - Text Primary: Charcoal (`#212529`)
  - Text Secondary: Slate Gray (`#6C757D`)
- **Typography:**
  - UI Font: `Inter`
  - Editorial & Display Headings: `Georgia`, `Playfair Display`, serif
- **Component Libraries:**
  - **Nuxt UI v4:** Primary component library for layout, navigation, inputs, modals, popovers, and badges.
  - **Apache ECharts (`echarts`):** Primary charting library for all data visualizations (line charts, donut charts, analytics).
  - **AG Grid (`ag-grid-vue3`):** Primary data grid for tabular CRUD views with built-in pagination.

## Verification Protocol

1. Run the most relevant verification command after making code modifications:

   - Backend: `.\mvnw compile` and `.\mvnw test`
2. Fix errors immediately, then stop.
3. Do not start/restart dev servers during verification.
